# 04 — `orbit.ai.*`

`@hrbr/orbit/ai` owns policy-scoped model contracts for execution. It is not a raw provider, Workers AI, or AI Gateway passthrough.

## Purpose

`orbit.ai.*` gives sandbox and job code model capabilities through Harbor policy, usage logging, and Cloudflare AI Gateway Unified Billing.

```text
   orbit.ai.* ──▶ Harbor runtime context ──▶ AI Gateway ──▶ approved providers/models
```

## Current runtime API

Runtime-only; no public Coast/API route is exposed for AI helpers.

```ts
orbit.ai.run(model, input, opts?)
orbit.ai.run(input, opts?)
orbit.ai.models(opts?)
orbit.ai.generate(input, opts?)
orbit.ai.embed(input, opts?)
orbit.ai.summarize(input, opts?)
orbit.ai.classify(input, opts?)
orbit.ai.rerank(input, opts?)
```

Sandbox/user code does not pass `workspace_id`. The runtime injects workspace/run context from the sealed execution envelope and records usage against that workspace.

## Gateway model ids

Model ids are Gateway-ready provider ids, for example:

```text
anthropic/claude-haiku-4-5-20251001
workers-ai/@cf/baai/bge-base-en-v1.5
workers-ai/@cf/meta/llama-3.3-70b-instruct-fp8-fast
```

Default text helpers use the current cheap Haiku model through AI Gateway Unified Billing. Embeddings use a cheap Gateway-compatible Workers AI embedding model through AI Gateway, not the raw Workers AI binding.

## Policy and audit

AI calls currently record into `orbit_usage_log`:

```text
workspace_id
run_id
operation: ai.run | ai.generate | ai.embed | ai.summarize | ai.classify | ai.rerank | ai.models
model
size_bytes
duration_ms
error
```

Future billing-grade metering can add token/cost/cache fields via `units_json` or a dedicated AI usage table.

## Non-goals

- No raw `env.AI` object.
- No direct Workers AI binding execution.
- No provider API key access from sandbox code.
- No direct AI Gateway admin API.
- No public Coast AI command in v1.
- No public `/orbit/ai/*` routes in v1.
