# 12 — `orbit.socket.*`

`@hrbr/orbit/socket` owns contracts for workspace-scoped realtime rooms backed by Harbor-owned Durable Objects.

## Purpose

`orbit.socket` gives jobs and exec code a safe WebSocket primitive without exposing raw Cloudflare bindings.

```text
Browser
  -> signed socket URL
  -> API socket connect route
  -> OrbitSocketRoomDO per workspace/channel

job / exec
  -> orbit.socket.url(channel)
  -> orbit.socket.broadcast(channel, event)
```

## Runtime surface

```ts
const { url } = await orbit.socket.url("build-status", {
  permissions: ["receive"],
  expires_in_seconds: 300,
})

await orbit.socket.broadcast("build-status", {
  type: "progress",
  percent: 75,
})

const stats = await orbit.socket.stats("build-status")
```

## Contracts

```ts
OrbitSocketChannel
OrbitSocketPermission
OrbitSocketUrlBody / Response
OrbitSocketBroadcastBody / Response
OrbitSocketStatsBody / Response
```

## Authorization model

- API calls include `workspace_id` and require workspace membership.
- Runtime calls derive workspace authority from the sealed run/job envelope.
- WebSocket upgrade traffic uses signed, expiring tokens generated by Harbor.
- Default socket permission is receive-only; client send permission must be explicit.
- Optional `allowed_origins` restrict browser origins for public app use.

## Durable Object backing

The implementation uses one Durable Object per `{workspace_id}:{channel}` coordination atom. The object:

- accepts WebSockets with Cloudflare's Hibernation API;
- stores per-connection metadata with `serializeAttachment()`;
- restores hibernated connections with `ctx.getWebSockets()`;
- handles `webSocketMessage`, `webSocketClose`, and `webSocketError`;
- never exposes raw Durable Object APIs to user code.

## Non-goals

- No raw Durable Object namespace, ID, storage, alarms, or SQL exposure.
- No arbitrary cross-workspace broadcast.
- No durable message history in v0.
- No custom domains or app-route WebSocket manifest changes in v0.
- No secret-bearing socket payloads.
